# Filter app screens

The first design for the LezWatch.TV filter app, exported from the private
"LezWatch Filter App" canvas. Each screen is a 390x844 phone layout at 2x.
Show names are made-up sample data.

The epic is [#14](https://github.com/LezWatch/pwa/issues/14). Each child issue
embeds the screens it builds.
